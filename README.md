## ✨ About

**HERmony** is an AI-powered women's wellness platform designed to go beyond traditional period tracking.

It combines **cycle health**, **mood tracking**, **PCOS management**, **mental wellness**, **AI-powered guidance**, **nutrition**, and **productivity insights** into one personalised experience.

Whether you're tracking your cycle, understanding mood changes, building healthier habits, or simply checking in with yourself, HERmony grows with you.

> *Because every phase deserves understanding, not uncertainty.*

# 🚀 Getting Started

### Clone Repository

```bash
git clone <repository-url>
cd HERmony
```

### Backend

```bash
cd backend

python -m venv .venv

source .venv/bin/activate
# Windows
.venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
