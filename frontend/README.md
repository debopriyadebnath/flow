# HERmony Frontend

Next.js 15 application for HERmony, an AI-powered women's wellness companion that helps users understand their cycle, track mood, manage PCOS symptoms, build healthy habits, and receive personalized wellness insights.

## Phase 1 scope
- Next.js App Router bootstrap
- TypeScript and Tailwind configuration
- Foundation for feature-first architecture

## Design direction
Soft lavender, light pink, white, rounded cards, accessible motion, and calm modern UI.
